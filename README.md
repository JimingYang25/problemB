件 3 给出了该水文站部分监测点的相关数据。
 请建立数学模型研究以下问题：

型分析在“调水调沙”期间，水沙通量的剧烈变化是如何驱动断面几何形状演化的（例如：是变

存在一个“演化稳态”。若未来不进行人为干预，请建立模型论证该断面形态将趋向于某种特定

2. 假设监测站的传感器存在一定的测量噪声和失效风险，且不同监测点（附件 3）之间存在空
间相关性。请建立一个“信息价值（Value of Information, VoI）”评估模型，量化每一个监测点

当水位每小时变化超过𝐻0时，采样频率提升为每𝑋小时一次；
当含沙量低于阈值𝑆0时，降低采样频率。

采样方案”。在相同采样次数下，哪种方案对年总排沙量的估算误差更小？请给出量化评价。

## 三、各模块详细设计

### Module 1：数据预处理

- [ ] 解析附件2的9个断面，提取 `起点距离` 和 `河底高程`
- [ ] 统一插值到相同的横向网格（间距1m）
- [ ] 输出：9条断面曲线的标准化数据


### Module 2：目标变量计算

对每个断面计算以下几何指标：

| 指标 | 符号 | 公式 | 物理意义 |
|:---|:---|:---|:---|
| 过水面积 | $A$ | $A = \int (Z_{ref} - z(x)) dx$ | 断面的输水能力 |
| 水面宽度 | $B$ | $B = \int \mathbf{1}_{z(x) < Z_{ref}} dx$ | 水面展宽程度 |
| 宽深比 | $\xi$ | $\xi = B^2 / A$ | 断面形态：越大越宽浅，越小越窄深 |
| 形态熵 | $H$ | $H = -\sum p_j \ln p_j$ | 断面复杂程度：越大越凹凸不平 |

> 注：参考水位 $Z_{ref}$ 固定取 **43m**

- [ ] 对9个断面分别计算 $A, B, \xi, H$
- [ ] 计算相邻断面之间的变化量 $\Delta A_i$, $\Delta \xi_i$（共8组）
- [ ] 输出：`断面指标汇总表`


### Module 3：驱动因子提取

对每两个相邻断面之间的时间段，聚合附件1的水沙数据：

| 驱动因子 | 符号 | 计算公式 |
|:---|:---|:---|
| 累计径流量 | $V_i$ | $\sum Q(t) \cdot \Delta t$ |
| 累计输沙量 | $M_i$ | $\sum Q(t) \cdot S(t) \cdot \Delta t$ |
| 最大洪峰流量 | $Q_{peak,i}$ | $\max Q(t)$ |

- [ ] 确定9个断面的时间节点
- [ ] 对8个时间段分别提取 $V_i, M_i, Q_{peak,i}$
- [ ] 输出：`驱动因子汇总表`


### Module 4：经验公式拟合

建立两个线性经验公式，用最小二乘法拟合：

**面积演化方程：**
$$\Delta A_i = a_1 \ln V_i + a_2 \ln M_i + a_3 Q_{peak,i} + a_4 + \varepsilon_i$$

**宽深比演化方程：**
$$\Delta \xi_i = b_1 \ln V_i + b_2 \ln M_i + b_3 Q_{peak,i} + b_4 + \eta_i$$

**判断规则：**

- $a_2$ 的符号判断冲刷/淤积
- $b_2$ 的符号判断窄深/宽浅

- [ ] 合并 Module 2 和 Module 3 的数据
- [ ] 用最小二乘拟合两个方程
- [ ] 检验系数的显著性（p-value）
- [ ] 输出：回归系数表 + 结论


### Module 5：稳态方程拟合

用Logistic增长方程刻画断面面积 $A(t)$ 的演化：

$$A(t) = \frac{A_{eq}}{1 + \left(\frac{A_{eq}}{A_0} - 1\right) e^{-r t}}$$

用9个时间点的 $A_i$ 做非线性最小二乘拟合，得到：

- $A_{eq}$：稳定平衡面积（核心结论）
- $r$：断面调整速率

**稳定性分析：**

$$f'(A_{eq}) = -r < 0 \quad \Rightarrow \quad \text{稳定平衡点}$$

- [ ] 将9个 $A_i$ 按时间排序
- [ ] 用非线性最小二乘拟合 Logistic 曲线
- [ ] 同样方法拟合 $\xi(t)$ 和 $H(t)$ 的指数衰减方程
- [ ] 输出：$A_{eq}, \xi_{eq}, H_{eq}$ + 平衡点稳定性结论


### Module 6：模型验证

采用**留一法交叉验证（LOOCV）**：

1. 每次留出1个断面作为测试集，剩余8个作为训练集
2. 训练经验公式，预测被留出的断面
3. 循环9次，计算总误差

$$RMSE = \sqrt{\frac{1}{9}\sum_{i=1}^{9} (\hat{y}_i - y_i)^2}$$

$$MAPE = \frac{1}{9}\sum_{i=1}^{9} \frac{|\hat{y}_i - y_i|}{|y_i|} \times 100\%$$

- [ ] 实现留一法循环
- [ ] 计算 RMSE 和 MAPE
- [ ] 输出：验证结果 + 结论

## 六、附录：关键公式速查

### 6.1 几何指标

$$A = \int_{z(x) < Z_{ref}} (Z_{ref} - z(x)) dx$$

$$B = \int \mathbf{1}_{z(x) < Z_{ref}} dx$$

$$\xi = \frac{B^2}{A}$$

$$H = -\sum_{j=1}^{K} p_j \ln p_j$$

### 6.2 驱动因子

$$V = \sum Q(t) \cdot \Delta t$$

$$M = \sum Q(t) \cdot S(t) \cdot \Delta t$$

$$Q_{peak} = \max Q(t)$$

### 6.3 经验公式

$$\Delta A = a_1 \ln V + a_2 \ln M + a_3 Q_{peak} + a_4$$

$$\Delta \xi = b_1 \ln V + b_2 \ln M + b_3 Q_{peak} + b_4$$

### 6.4 稳态方程

$$A(t) = \frac{A_{eq}}{1 + (A_{eq}/A_0 - 1)e^{-rt}}$$

$$\xi(t) = \xi_{eq} + (\xi_0 - \xi_{eq})e^{-r_\xi t}$$

$$H(t) = H_{eq} + (H_0 - H_{eq})e^{-r_H t}$$

### 6.5 验证指标

$$RMSE = \sqrt{\frac{1}{n}\sum(\hat{y}_i - y_i)^2}$$

$$MAPE = \frac{1}{n}\sum \frac{|\hat{y}_i - y_i|}{|y_i|} \times 100\%$$



关键结果摘要

2. 经验公式（回归系数）
ΔA: R² = 0.26 — 泥沙输运↑→面积↓（淤积为主），a₂ = -2082
Δξ: R² = 0.07 — 泥沙输运↑→河道变宽变浅，b₂ = +113
3. 稳态分析
平衡面积 A_eq ≈ 2881 m²（稳定平衡点，f'(A_eq) = -0.0028 < 0）
半衰期 ≈ 248 天，表示若无人为干预，断面将在 ~0.7 年内朝平衡态调整
结论：断面趋向稳定平衡而非不可逆崩溃
4. 模型局限性
LOOCV 的 RMSE/MAPE 很大，根本原因是只有 8 个数据间隔（9 个断面），而河流断面受季节性洪水和调水调沙事件驱动，波动远超简单线性/Logistic 模型的表达能力。论文中应如实讨论这一局限性，并建议增加断面测量频次。
